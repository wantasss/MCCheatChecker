# Disclaimer & Acceptable Use Policy

## Project Purpose
MCCheatChecker is an open-source forensic inspection and server administration tool created for Minecraft server administrators and moderators to perform authorized screen-sharing (SS) integrity checks.

## Responsible Use
* This software is intended solely for administrative, educational, and game-server moderation purposes.
* It operates in a read-only manner on the local machine to audit process memory, event logs, and file system indicators for fair-play rule violations.
* This tool does not contain malware, trojans, backdoors, remote administration tools (RATs), keyloggers, or unauthorized surveillance mechanisms.
* Users are responsible for ensuring that all checks comply with applicable local laws and obtain consent where required.
